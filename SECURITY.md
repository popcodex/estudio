# Seguridad

Estudio está diseñado para uso local individual. No despliegues el servidor como un servicio público.

No publiques vulnerabilidades con datos privados en un issue abierto. Si el repositorio permite avisos privados de seguridad, utiliza esa vía; en caso contrario, contacta al titular mediante un canal privado que este haya publicado. No se define aquí una dirección de contacto ficticia.

Los archivos de biblioteca, ajustes, respaldos, variables de entorno y credenciales deben permanecer fuera de Git. El proyecto no incluye credenciales de servicios externos.
