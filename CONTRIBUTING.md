# Contribuciones

Antes de proponer cambios, consulta el README y el alcance de la versión. La licencia del código propio está pendiente de elección; acuerda cualquier contribución o redistribución con el titular.

Para reportar un problema, incluye pasos reproducibles, versión de macOS y Node, comportamiento esperado y resultado observado. Usa exclusivamente ejemplos ficticios. No adjuntes bibliotecas personales, tokens, rutas privadas ni archivos de clientes.

Para una propuesta de cambio, explica el problema, el comportamiento resultante y las pruebas ejecutadas. Ejecuta la reconstrucción del editor y la suite cuando corresponda. Mantén los cambios de producto separados de los datos locales.
